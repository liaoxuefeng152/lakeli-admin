## 项目经历

### 项目一：域途 GEO SaaS — AI 搜索引擎优化平台（全栈独立开发）

**时间**：2025.06 - 至今
**角色**：全栈开发工程师（独立负责）
**技术栈**：Next.js 16、React 19、TypeScript 5、Tailwind CSS v4、shadcn/ui、Recharts、PostgreSQL、Drizzle ORM、Supabase、火山引擎豆包 LLM、DeepSeek、通义千问、Docker、Nginx

**项目简介**：面向品牌方的 AI 搜索引擎优化 SaaS 平台，帮助品牌在豆包、DeepSeek、通义千问等 9 大 AI 平台获得更高推荐率与可见度。对标业内 GENO 系统，在 Agent 自主优化闭环、全产品生态联动、私有化部署三个维度实现差异化超越。

**核心成果**：

1. **全局行动型 AI 助手 Agent**：设计并实现从"纯问答"到"行动型"的架构升级。通过 LLM 意图识别引擎（支持 9 类意图：诊断/文案/关键词/监测/分发等），将用户自然语言指令直接转化为后端真实接口调用，并在对话气泡内呈现结构化结果卡片（评分环形图、文案预览、关键词标签等）。实现多轮对话参数回填、30s 超时保护、三级错误分类诊断（网络/超时/HTTP），LLM 不可用时如实反馈而非伪造数据。

2. **多模型 Provider 架构与 SDK 适配层**：将原 `coze-coding-dev-sdk` 替换为自研 OpenAI 兼容适配层（`@/lib/sdk-adapter`），统一接入火山引擎豆包、DeepSeek、通义千问三大 Provider，支持 `invoke()` 和 `stream()` 双模式。发现并修复了因 SDK 环境变量不兼容导致的全站 LLM 静默降级问题（所有调用失败后降级到关键词匹配，用户无感知）。

3. **AI 收录监测系统**：设计 BVI（品牌可见度指数）0-100 评分模型（推荐率×0.35 + 首位率×0.25 + 正向情感×0.20 + 信源权威×0.20），支持 9 大 AI 平台并行探测，LLM 不可达时自动降级为确定性仿真，保证页面始终可渲染。

4. **优化 Agent 自主闭环**：实现"异常感知→根因诊断→策略生成→内容创生→分发→验证"6 阶段闭环流程，关键阶段设人工审批门控（人类在环），实现 Agent 自主执行 + 人类兜底的安全架构。

5. **品牌知识图谱 + RAG 联动**：LLM 从品牌文本抽取结构化三元组（主体-关系-客体），版本链管理，支持一键同步至龙掌柜 RAG 知识库（`ke.knowledge_entries`），实现"AI 搜索推荐"与"AI 助手回答"同源一致。

6. **基础设施**：Docker 多阶段构建 + docker-compose（App + PostgreSQL + Nginx）三服务编排，Nginx 反代含网关限流、安全响应头、SSE 流式穿透，支持私有化部署。

**项目简介**：公司全产品一体化统一管理中台，采用"统一底座 + 业务模块化插件"架构，集成 7 大业务模块（龙掌柜 AI 助手、域途 GEO SaaS、智推 AI 客服、智能外呼、跨境外贸知识引擎、拉客力数据中台、后台管理），共计 45+ 页面。

### 项目三：lakeli-app-xc — AI 智能体中台后端（核心开发）

**时间**：2025.03 - 至今
**角色**：后端开发工程师
**技术栈**：Next.js 16 API Routes、TypeScript 5、PostgreSQL、Drizzle ORM、Supabase、OpenAI SDK、火山引擎 Ark、Playwright、Docker

**项目简介**：为前端管理后台与 AI 智能体提供统一后端服务，承载 20+ API 模块、36+ 张数据库表、7 种 AI 技能、GEO 全链路引擎、多模型 Provider 调度。

**核心成果**：

1. **Drizzle ORM Schema 设计**：设计 4 个 PostgreSQL Schema（`lzg` 龙掌柜 8 表、`admin` 管理后台 5 表、`geo` GEO 系统 13 表、`ke` 知识引擎 10 表），共计 36+ 张表，覆盖用户/会话/资产/技能/监测/知识图谱/计费等全业务域。

2. **AI 技能系统**：设计可扩展的技能注册中心（`SkillRegistry`），通过关键词+正则匹配实现意图路由，内置 7 种技能：AI 作图（白底图/场景图/模特图）、AI 视频生成、AI 选品（市场趋势分析）、上架优化（标题/五点/关键词）、广告优化（PPC/ACOS/ROAS）、自动客服（意图分类+情感分析+自动回复）、浏览器自动化（Playwright 批量上架/数据采集）。

3. **GEO 全链路引擎**：实现诊断（FetchClient 抓取+LLM 分析+反爬检测）、文案生成（SSE 流式 + 65 种语言）、关键词挖掘、外链分析、自动建站等核心引擎，支持 LLM 不可达时的确定性仿真降级。

4. **多模型自动路由**：根据用户消息关键词自动匹配最佳模型（分析/深度/报告 → DeepSeek V4 Pro，日常对话 → 豆包 Lite），实现模型资源按需调度。

5. **监测数据回流数据中台**：BVI/推荐率/情感等监测数据写入 `dp.fact_brand_mention` 事实表，自动注册为 `dp.dp_metric_definitions` 正式指标，实现 GEO 数据全产品可查询。
